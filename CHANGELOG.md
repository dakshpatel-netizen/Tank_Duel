# Changelog

## v1.0.0 — Initial Release
- Implemented complete 3D multiplayer tank battle arena (`Tank Duel Online`).
- Added 3 tank classes (`Scout`, `Standard`, `Heavy`), 3 turret styles, 6 hull decals, and 12 hull colors.
- Added 6 maps with Small/Medium/Large scaling and procedural 640x360 preview cards.
- Added 5 game modes (`FFA`, `TDM`, `LTS`, `CTF`, `KOTH`), 13 Power Box items, and offline Practice vs Bots.
- Added Neon Arcade Glass UI, Battle HUD, 3D podium results with confetti, 6-tab Settings modal, and Web Audio synthesizer.
